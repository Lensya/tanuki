Поиск автозапчастей

Как пользоваться быстрым поиском
Как пользоваться быстрым поиском
1й способ: Поиск по производителю и модели
  1. Выберите производителя (марку) вашего транспортного средства.
  2. Выберите модель.
  3. Нажмите кнопку «Найти запчасть» — система покажет все доступные товары для выбранной модели
  4. Либо сразу выберите нужную запчасть из списка и нажмите на неё.

Этот способ поиска выдаёт наиболее полный результат.

2й способ: Поиск с уточнением по кузову
  1. Если при использовании 1-го способа отобразилось слишком много вариантов, введите в поле дополнительного параметра короткий номер кузова, например: AZT240
  2. Если запчасть используется на нескольких кузовах одной модели, укажите их через пробел, например: AZT240 NZT240 ZZT240 ZZT245
  3. Нажмите кнопку «Найти запчасть» — система отобразит товары, соответствующие уточнённым параметрам.
  4. Или выберите нужную запчасть из предложенного списка и нажмите на неё.

Пожелания по добавлению названий моделей и запчастей просьба направлять сообщением менеджеру.
